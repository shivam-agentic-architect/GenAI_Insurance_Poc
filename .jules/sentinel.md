## 2025-02-28 - Removed hardcoded admin credentials from frontend bundle
**Vulnerability:** The application was performing authentication validation on the client-side (`src/App.tsx`), hardcoding the username `shivam` and password `charan1` directly into the bundled source code. This made the credentials trivial to extract and allowed an attacker to bypass authentication logic or reuse credentials.
**Learning:** Client-side authentication checks expose credentials and logic to anyone accessing the site. Furthermore, even Vite environment variables (`import.meta.env`) shouldn't be used to store secrets as they are statically injected into the client bundle.
**Prevention:** Always perform authentication validation on a trusted backend server. Never store sensitive credentials in client-side code or Vite environment variables. Store secrets securely as standard server-side environment variables (`process.env`) and compare them within secure API endpoints like `/api/login`.
